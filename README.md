# EthicalAI

Small, readable projects that use AI and software for ethical goals.

| Project | What it does | Status |
|---|---|---|
| [**airlock**](airlock/) | Finds prompt injection in untrusted text (invisible Unicode, hidden HTML, override phrases, exfiltration links) **before an AI agent reads it**, then explains it and sanitizes it. Zero dependencies. | ![tests](https://img.shields.io/badge/tests-27%20passing-brightgreen) |

Each project lives in its own folder with its own README, tests and examples.
