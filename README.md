# EthicalAI

Different projects using AI for ethical-focused goals.

| Project | What it does |
|---|---|
| [**Parity**](parity/) | Zero-dependency bias audit for automated decision systems. Checks hiring (or lending, housing…) decisions for disparate impact under NYC Local Law 144 and the EEOC four-fifths rule, intersections included. Produces audit-ready HTML/Markdown reports and CI exit codes. |
