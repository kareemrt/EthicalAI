# EthicalAI
Different projects using AI for ethical-focused goals.

| Project | What it does |
|---|---|
| [**⚖️ Parity**](parity/) | A zero-dependency tool that audits automated decisions (hiring, lending, housing) for disparate impact. It applies the four-fifths rule, NYC LL144-style intersectional impact ratios, significance tests and fragility checks, and writes plain-language findings and HTML reports. |
