# EthicalAI

Different projects using AI for ethical-focused goals.

| Project | Problem | What it does |
|---|---|---|
| [**plainspeak**](plainspeak) | People lose food aid, health coverage, and housing because official letters are unreadable. | Scores a notice for reading level, jargon, passive voice, and the essentials a reader needs to act (deadline, next step, help, appeal). Outputs terminal, HTML, or JSON reports and can gate templates in CI. Zero dependencies. |
