# EthicalAI
Different projects using AI for ethical-focused goals.

| Project | Problem | What it does |
|---|---|---|
| [🔍 **FairLens**](fairlens/) | Automated hiring, lending and admissions systems can quietly discriminate. New laws (NYC LL144, EU AI Act) require bias audits. | A zero-dependency CLI that audits a CSV of decisions for adverse impact (four-fifths rule, significance testing, equalized odds, intersectional groups) and writes a publishable report and chart. |
