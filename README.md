# EthicalAI
Different projects using AI for ethical-focused goals.

| Project | What it does |
|---|---|
| [**fairscope**](fairscope/) | Zero-dependency bias auditor for automated decisions (hiring, lending, screening). Computes impact ratios (four-fifths rule, NYC LL144), significance, intersectional and equal-opportunity gaps. Produces Markdown/HTML/JSON reports and can act as a CI gate. |
