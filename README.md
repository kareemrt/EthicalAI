# EthicalAI

Projects that apply data and AI toward ethical, public-interest goals.

| Project | What it does | Stack |
|---|---|---|
| [**⚖️ Parity**](parity/) | Bias audits for automated decision systems (hiring, lending, screening). Applies the four-fifths rule and NYC Local Law 144 impact ratios, with intersectional analysis and **proxy-feature detection**. Produces HTML/Markdown/JSON reports and works as a CI gate. | Python, zero dependencies |

Each project lives in its own folder with its own README.
