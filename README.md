# EthicalAI
Different projects using AI for ethical-focused goals.

| Project | What it does |
|---|---|
| [**FairLens**](fairlens/) | Audits automated decision systems (hiring, lending, benefits) for adverse impact using the EEOC four-fifths rule and NYC Local Law 144 impact ratios, with significance tests, error-rate fairness and intersectional analysis. Needs only one CSV and has no dependencies. |
